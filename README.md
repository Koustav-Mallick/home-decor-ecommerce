# HOME_DECOR - Premium E-Commerce

A fully responsive, premium home decor e-commerce website built from scratch using WordPress, Elementor, and WooCommerce. 

## 📖 About The Project

The goal of this project was to move beyond standard WooCommerce templates and engineer a luxurious, high-end shopping experience. The design focuses on clean aesthetics, perfect grid alignment, and a seamless user journey from product discovery to checkout. 

### 🎥 Live Demo / Showcase
[Watch the full project showcase on YouTube](https://youtu.be/2CXg8h3-rVs)

## ✨ Key Features

*   **Dynamic Custom Storefront:** Engineered a custom Home and Shop page featuring perfectly aligned, Flexbox-powered product grids.
*   **Custom Brand Identity:** Implemented an earthy-minimalist color palette (Warm Gold, Matte Black, Soft Beige) with a seamlessly integrated 1:1 logo.
*   **Optimized Navigation:** Developed a custom header with a promotional top bar and a comprehensive, multi-column footer layout.
*   **Customer Support & UX:** Built a "Contact Us" page featuring integrated Everest Forms and interactive FAQ accordions to handle customer inquiries efficiently.
*   **Trust & Social Proof:** Designed an "About Us" page equipped with animated credibility counters and a modern split-screen brand story section.

## 🛠️ Tech Stack & Plugins

*   **CMS:** WordPress
*   **Page Builder:** Elementor
*   **E-Commerce Engine:** WooCommerce
*   **Grid Extensions:** Essential Addons for Elementor
*   **Forms:** Everest Forms
*   **Styling:** Custom Flexbox implementation for uniform product card alignment.
